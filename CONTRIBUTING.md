# Contributing to Wash ERP

Thank you for your interest in contributing! Here are some guidelines to help you get started.

## How to Contribute

1.  **Fork the repository** on GitHub.
2.  **Clone your fork** to your local machine.
3.  **Create a branch** for your feature or bug fix: `git checkout -b my-new-feature`.
4.  **Make your changes** and ensure the code follows the project's style.
5.  **Run linting and build tests**: `npm run lint` and `npm run build`.
6.  **Commit your changes**: `git commit -am 'Add some feature'`.
7.  **Push to the branch**: `git push origin my-new-feature`.
8.  **Submit a pull request** to the `main` branch.

## Reporting Issues

If you find a bug or have a feature request, please search the existing issues before opening a new one. When reporting an issue, provide as much detail as possible, including steps to reproduce the bug.

## Code of Conduct

Please be respectful and professional in all interactions within the project community.
