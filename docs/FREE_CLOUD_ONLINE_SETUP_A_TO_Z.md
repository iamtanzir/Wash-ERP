## 🚀 পদ্ধতি ১: Cloudflare Free Tunnel (পিসি বা Raspberry Pi থেকে ১-ক্লিকে অনলাইন)

এই পদ্ধতিতে আপনার ফ্যাক্টরির পিসি বা Raspberry Pi-তে সফটওয়্যারটি চলবে এবং ক্লাউডফ্লেয়ারের ফ্রি টানেলের মাধ্যমে বিশ্বব্যাপী যেকোনো জায়গা থেকে এক্সেস করা যাবে। **কোনো রাউটার পোর্ট ফরওয়ার্ডিং বা পাবলিক আইপি লাগবে না।**

### উইন্ডোজ (Windows PC) সেটআপ:
1. `start-online-tunnel.bat` ফাইলে ডাবল ক্লিক করুন।
2. স্ক্রিপ্টটি স্বয়ংক্রিয়ভাবে লোকাল ইআরপি চালু করবে এবং ক্লাউডফ্লেয়ার টানেল ডাউনলোড করে একটি ফ্রি পাবলিক লিঙ্ক তৈরি করবে:
   ```
   https://[random-string].trycloudflare.com
   ```
3. এই লিঙ্কটি কপি করে আপনার মোবাইল ব্রাউজারে খুলুন কিংবা অ্যাডমিন প্যানেলে সেভ করুন।
4. এখন ঢাকা অফিস বা যেকোনো জায়গা থেকে লগইন করে অর্ডার এন্ট্রি, ফেব্রিক রিসিভ/ডেলিভারি এবং ওয়াশ স্টেজ আপডেট করুন!

### রাস্পবেরি পাই (Raspberry Pi 3/4/5) সেটআপ:
1. টার্মিনালে নিচের কমান্ডটি চালান:
   ```bash
   chmod +x start-online-tunnel.sh
   ./start-online-tunnel.sh
   ```
2. টার্মিনালে আপনি একটি `https://xxxx.trycloudflare.com` লিঙ্ক দেখতে পাবেন।
3. Raspberry Pi বিদ্যুৎ সাশ্রয়ী হওয়ায় এটি ফ্যাক্টরিতে ২৪ ঘণ্টা চালু রেখে সারা বিশ্ব থেকে লাইভ ডাটা এন্ট্রি করা সম্ভব।

## ☁️ পদ্ধতি ২: Turso ১০০% ফ্রি ক্লাউড ডাটাবেজ (9 GB LibSQL)

টারসো (Turso) হলো বিশ্ববিখ্যাত সার্ভারলেস SQLite ক্লাউড ডাটাবেজ, যা মাসে **৯ জিবি স্টোরেজ ও ১ বিলিয়ন রিড সম্পূর্ণ ফ্রিতে** দেয়।

### ধাপসমূহ (Step-by-Step):
1. **অ্যাকাউন্ট তৈরি:** [https://turso.tech](https://turso.tech) এ গিয়ে বিনামূল্যে GitHub দিয়ে সাইনআপ করুন।
2. **ডাটাবেজ তৈরি:**
   - টারসো ড্যাশবোর্ডে গিয়ে **Create Database** ক্লিক করুন অথবা CLI-তে লিখুন:
     ```bash
     turso db create inctl-wash-erp
     ```
3. **কানেকশন URL ও Token সংগ্রহ:**
   - Database URL টি দেখতে এরকম হবে: `libsql://inctl-wash-erp-[your-user].turso.io`
   - একটি Auth Token জেনারেট করুন:
     ```bash
     turso db tokens create inctl-wash-erp
     ```
4. **ইআরপি সিস্টেমে বসানো:**
   - আপনার ইআরপির **HOST & CLOUD ADMIN** মেনুর **Database Mode** ট্যাবে যান।
   - **Turso Cloud Database (LibSQL)** অপশনটি সিলেক্ট করুন।
   - আপনার `Database URL` এবং `Auth Token` পেস্ট করে **Save & Connect Database** এ ক্লিক করুন।
5. **ফলাফল:** এখন আপনার ইআরপির ডাটা কোনো সিঙ্গেল পিসিতে সীমাবদ্ধ নয়—ক্লাউডে লাইভ সেইভ হবে এবং যেকোনো স্থান থেকে তাৎক্ষণিক সিঙ্ক হবে!

## 🌐 পদ্ধতি ৩: Vercel-এ ২৪/৭ ফ্রি ক্লাউড ওয়েব হোস্টিং ($0 Cost)

ফ্যাক্টরির পিসি বন্ধ থাকলেও যেন ২৪ ঘণ্টা সফটওয়্যার চালু থাকে, তার জন্য Vercel হলো সেরা সমাধান।

1. আপনার কোডটি GitHub-এ পুশ করুন।
2. [https://vercel.com](https://vercel.com) এ লগইন করে **Add New Project** ক্লিক করে রিপোজিটরিটি ইমপোর্ট করুন।
3. **Environment Variables** সেকশনে নিচের ভেরিয়েবলগুলো যোগ করুন:
   - `DATABASE_MODE` = `turso`
   - `TURSO_DATABASE_URL` = `libsql://inctl-wash-erp-xxx.turso.io`
   - `TURSO_AUTH_TOKEN` = `[আপনার টারসো টোকেন]`
   - `JWT_SECRET` = `[যেকোনো গোপন কি]`
4. **Deploy** বাটনে ক্লিক করুন। ২ মিনিটের মধ্যে আপনার ইআরপি লাইভ হবে:
   ```
   https://inctl-wash-erp.vercel.app
   ```
5. এখন মোবাইল, ট্যাবলেট ও ল্যাপটপে যেকোনো ব্রাউজারে বুকমার্ক করে ব্যবহার করুন।

## 📁 পদ্ধতি ৪: গুগল ড্রাইভ (Google Drive) ১৫ জিবি ফ্রি অটো-ব্যাকআপ ও সিঙ্ক

গুগল ড্রাইভের ১৫ জিবি ফ্রি স্টোরেজ ব্যবহার করে ডে-টু-ডে ডাটা চিরতরে ব্যাকআপ রাখার নিয়ম:

### ১-ক্লিক ম্যানুয়াল ব্যাকআপ:
- **HOST & CLOUD ADMIN** -> **Google Drive 15GB Cloud DB** ট্যাবে যান।
- **Export Complete Database Package** বাটনে ক্লিক করলে সমস্ত অর্ডার, ফেব্রিক ট্র্যাকিং, ডেইলি লগ এবং বায়ার ডাটা ব্যাংক একটি সম্পূর্ণ JSON ফাইলে ডাউনলোড হবে।
- ফাইলটি আপনার গুগল ড্রাইভের একটি ফোল্ডারে (যেমন `INCTL_ERP_Backups`) ড্র্যাগ করে রেখে দিন।

### স্বয়ংক্রিয় ব্যাকআপ (Automated Sync via rclone):
- উইন্ডোজ বা রাস্পবেরি পাইতে `rclone` ইন্সটল করুন:
  ```bash
  # Linux / RPi
  sudo apt install rclone -y
  rclone config
  # New remote 'gdrive', select Google Drive
  ```
- ক্রনজব (Cronjob) সেট করে প্রতিদিন রাত ১২টায় অটোমেটিক ব্যাকআপ ড্রাইভে পাঠাতে পারেন:
  ```bash
  0 0 * * * rclone sync /path/to/inctl-wash-erp/data/gdrive_backups gdrive:INCTL_ERP_Backups
  ```

## 📱 ফ্যাক্টরি ফ্লোর মোবাইল ও ট্যাবলেট ডাটা এন্ট্রি নির্দেশিকা

1. ফ্যাক্টরি ফ্লোরের সুপারভাইজার বা কিউসি ইনচার্জের মোবাইলে ইন্টারনেট ব্রাউজার (Chrome/Safari) খুলুন।
2. আপনার ইআরপির অনলাইন লিঙ্কটি প্রবেশ করান (অথবা অ্যাডমিন প্যানেল থেকে তৈরি হওয়া **QR Code** মোবাইল ক্যামেরা দিয়ে স্ক্যান করুন)।
3. নিজের ইউজারনেম ও পাসওয়ার্ড দিয়ে লগইন করুন (Operator বা Editor রোল)।
4. সহজে ডাটা এন্ট্রি করুন:
   - **Order Management:** নতুন স্টাইল, বায়ার ও কোয়ান্টিটি এন্ট্রি।
   - **Fabric CPL Tracking:** ফেব্রিক রিসিভ, ডেলিভারি ও সাব-ফ্যাক্টরি চালান পোস্টিং।
   - **Garments Tracking:** ওয়াশিং প্ল্যান্টের প্রতিটি ফ্লোরভিত্তিক স্টেজ আপডেট (Dry Process, Wet Process, Hydro, Dryer, Quality)।
   - **Buyer Dashboard:** বায়ারভিত্তিক ডেলিভারি প্রগ্রেস ও ব্যালেন্স মনিটরিং।
